03 / METHOD AND LIMITS

Text export → local parser → aggregate patterns

Supported examples: 31/12/2023, 11:05 PM - Name: message and [31/12/2023, 23:05:10] Name: message. Dots or hyphens between date parts are also accepted. Select DMY or MDY explicitly; ambiguous dates are not automatically guessed.

Multiline continuations attach to the previous message. System entries without a sender delimiter are counted separately. Invalid headers and unparsed lines are reported. Localized timestamp markers, unusual exports and ambiguous quoted headers may require parser changes.

Media means a recognized omission marker, not the number of actual attachments. Edited/deleted messages, incomplete exports and parsing differences affect counts. Activity cannot establish sentiment, effort, health or the quality of a relationship.

Input limits: 10 MiB, 200,000 lines, 100,000 messages and 5,000 participants. The analysis returns aggregate buckets, not message bodies. The worker is terminated after analysis; Clear removes the displayed result and file selection. Normal browser/hosting requests can reveal routine connection metadata, but chat text is not sent by this application.
